# coolweather — 酷欧天气实战项目

跟随《第一行代码》教材练习的 Android 天气应用，实践网络请求、JSON 解析与界面展示。

## 项目简介

酷欧天气是《第一行代码》教材中的实战项目，完整走通了从天气数据获取到界面呈现的 Android 开发流程。项目练习了 HTTP 网络请求、JSON 数据解析、列表与详情界面展示等核心能力，是 Android 入门阶段的重要练手项目。

## 技术特色与复盘

### 技术亮点

- 网络请求：使用 HTTP 接口获取天气数据，练习了 Android 网络通信的基础用法
- JSON 解析：对接口返回的 JSON 数据进行解析与数据模型封装
- 界面展示：通过列表展示城市天气信息，实现数据到 UI 的呈现

### 个人贡献

独立完成整个教材实战项目，跟随教材逐步实现网络请求、数据解析与界面展示等模块。

### 收获与规划

通过本项目掌握了 Android 网络请求与数据解析的基本流程，为后续更复杂项目的开发打下基础。项目作为教材实战练手内容归档保留。
